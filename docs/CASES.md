# 三个案例：收益、取舍与限制

以下均来自候选16的开发回归题，不属于冻结后的12道新题。这里展示书面方案的差异，未实施这些方案，也没有独立真人评审。

## S06：把隐私边界变成可操作的服务流程

社区法律信息桌只有两名志愿者、一张桌子、既有印刷资料和安静角落，不能提供法律建议，也不能让来访者在等候区公开讲私事。

强提示的最佳方案用无案情问句和匿名纸号，区分一般资料询问与需要合格人员处理的个案。拓展后的方案进一步取消整个到访过程的个案收集：可直接取资料、要求朗读或匿名等候；有人开始讲案情时，志愿者说明界线并及时打断。既有资料没有适合的转介渠道，就明确承认缺口。

它还提出六次虚构到访排练，检查找路、等候、无必要披露和缺少可理解下一步的问题。两次反序评审均选拓展方案；有效主要机制为强提示5种、拓展7种，同机制的队列升级没有重复计数。

**意义：**改进落实在具体服务边界。声学隐私、转介资料和真实来访结果仍需现场检查。

## N16：处理归档中断，也增加了检索负担

共居家庭的两位成年人各自管理药品说明纸，只能使用现有文件夹、信封、架子和纸标签；不能改变剂量或替代临床建议。

强提示方案提供私人文件夹、中性编码和内部索引。拓展方案针对归档被打断的情况，增加一个不透明的待归档信封，下一次查找先查它；如果积压难以检索，就停止此步骤、回到直接归档。一个评审选择两池共有方案而判平，另一个认为这一恢复步骤更可执行而判胜。

**取舍：**少一次随手放置，可能意味着每次多查一个位置。试行要观察检索时间、错放与积压，不能直接推断新增步骤值得采用。

整个31题的完整有效生成token比对照多11.20%；这是总体成本，不能写成此题的单独成本。

## Q05：高分不能消除约束判定分歧

任务只允许过去一年的公开鸟类观察汇总记录和志愿者出勤表，需要区分观察努力、季节和记录制度，不能直接把记录下降解释为鸟减少。

候选13、15、16的首三条方案逐字相同。候选15的两次评审都把使用未来资料的“后续观察”判为严重超出时间范围，因此即使最佳质量双胜，该题仍未达标。候选16改了后续拓展提示，但没有改这三条首轮方案；这次两评未标严重。

候选16的最佳拓展方案强调：旧记录口径无法可靠换算时，停止转换并分段报告。两评认为它更好，但这一书面优点不能消除共享首轮方案的风险。

**限制：**31/31是固定双评协议的结果，不代表所有约束问题已经消失。原票全部保留，没有额外加裁判翻票；本轮新题成绩也不能倒称为Q05修复证据。
